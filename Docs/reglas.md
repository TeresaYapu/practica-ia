# Reglas del Proyecto

1. **Idioma:** Todo el código, comentarios y mensajes de commit se escriben en español.
2. **Nombres:** Las variables y funciones se nombran en formato `snake_case` (ej: `sumar_numeros`).
3. **Seguridad:** Nunca borrar archivos ni exponer claves secretas.
4. **Ramas:** Todo cambio nuevo se trabaja en una rama (`feat/...` o `fix/...`), nunca directo en `main`.
5. **Pruebas:** Cada función nueva debe incluir un ejemplo de prueba al final.
