# 🚀 Práctica IA - Teresa Yapu

Proyecto de entrenamiento en desarrollo con IA y buenas prácticas de ingeniería.

## 📦 Proyectos incluidos
1. **Calculadora:** Funciones básicas (`sumar`, `restar`, `multiplicar`, `dividir`).
2. **Gestor de Tareas:** Aplicación de consola con persistencia de datos en `tareas.json`.

## 🛠️ Cómo ejecutar el Gestor de Tareas
**ejecutar en la terminal:** `python gestor_tareas.py`

### Opciones del menú:
1. ➕ Agregar tarea
2. 📋 Listar tareas
3. ✅ Marcar tarea como completada
4. 🗑️ Eliminar tarea
5. 🚪 Salir
